## About Me

I'm Zakiya, a B.Tech Computer Science student and an aspiring Software Developer and Java Developer who loves turning ideas into working software. I mostly code in Java and enjoy building backend projects with Spring Boot, from login systems to a Java-based vector database that I'm especially proud of. I practice data structures and algorithms regularly because I enjoy the thrill of breaking a hard problem into simple patterns, and I'm preparing for software engineering roles. Outside of coding, I like learning in public, sharing what I understand, and helping others find easier ways to study. I believe consistency beats talent, so I try to improve a little every day. I'm always open to learning new tools, collaborating on projects, and growing as a developer.
